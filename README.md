Four learning projects focused on entry-level IT support and end-user computing.

1. [Small Business Network Design](network-design/README.md)
2. [Grafana Infrastructure Monitoring](grafana-monitoring/README.md)

Add real screenshots and troubleshooting notes as you complete each lab.

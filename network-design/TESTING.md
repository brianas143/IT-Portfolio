# Packet Tracer verification checklist

- [ ] Router and switch ports are up; `show ip interface brief`
- [ ] Switch VLANs and trunk correct; `show vlan brief`, `show interfaces trunk`
- [ ] Employee PC can ping 192.168.10.1
- [ ] Guest PC can ping 192.168.20.1
- [ ] Server PC can ping 192.168.30.1
- [ ] Guest cannot ping employee or server PCs (ACL expected denial)
- [ ] Save Packet Tracer file and real screenshots in an evidence folder

Do not mark a check until you have verified it.
